# 🎟️ VIBETIX – Entertainment Event & Ticket Booking Website

**VIBETIX** is a modern, user-friendly entertainment event discovery and ticket booking website. It allows users to explore movies, comedy shows, concerts, theatre performances, and festivals in one place.

## ✨ Features

- 🎬 **Explore Events:** Browse movies, comedy shows, concerts, theatre performances, and festivals.
- 🔍 **Search & Filter:** Find events by name, category, city, and price.
- 🎯 **VibeMatch Recommendations:** Discover events based on mood and budget.
- 💺 **Interactive Seat Selection:** Select available seats for demo bookings.
- 💰 **Price Calculation:** View ticket costs in Indian Rupees (₹).
- 🎫 **Booking Confirmation:** Generate a demo booking confirmation and ticket.
- 👤 **Demo User Accounts:** Frontend-only sign-up and login interface.
- ❤️ **Favourites:** Save preferred events.
- 📱 **Responsive Design:** Designed for a smooth experience across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- SVG for icons and graphics

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore events and try the interactive demo features.

## 📌 Project Scope

VIBETIX is currently a **frontend demonstration project**. Event listings, seat availability, bookings, and user accounts are sample/demo features.

It does not currently include a real backend, secure authentication, live event inventory, payment gateway, or production AI integration.
